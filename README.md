# Five City - اختبار التفعيل 🎮

موقع متطور واحترافي لاختبار التفعيل في **Five City** مع تصميم حديث وألوان RGB داكنة.

## ✨ المميزات

- 🎨 **تصميم احترافي**: واجهة حديثة مع ألوان RGB داكنة
- ✨ **تأثيرات بصرية**: انتقالات سلسة وتأثيرات جميلة
- 📱 **متجاوب**: يعمل بشكل مثالي على جميع الأجهزة والشاشات
- 🎯 **أسئلة شاملة**: 8 أسئلة اختبار الالتزام بالقوانين
- 📊 **نتائج فورية**: عرض النتائج والنسبة المئوية مباشرة
- 🔄 **تجربة سلسة**: إمكانية الرجوع والتقدم بين الأسئلة

## 🎨 الألوان المستخدمة (RGB)

| اللون | RGB | الاستخدام |
|-------|-----|----------|
| **وردي/ماجنتا** | `255, 0, 127` | اللون الأساسي والحدود |
| **سماوي** | `0, 255, 255` | النصوص الثانوية |
| **أخضر** | `0, 255, 127` | التركيز والاختيارات |
| **خلفية داكنة** | `#0a0e27` | الخلفية الرئيسية |

## 🚀 كيفية الاستخدام

### الطريقة 1: عبر المتصفح مباشرة
1. افتح ملف `index.html` في متصفح الويب
2. اقرأ الأسئلة بعناية
3. اختر الإجابات الصحيحة
4. انقر "التالي" للتقدم إلى السؤال التالي
5. انقر "إنهاء" لعرض النتائج

### الطريقة 2: عبر الإنترنت
- يمكن نشر المشروع على GitHub Pages أو أي منصة استضافة

## 💻 المتطلبات التقنية

- متصفح ويب حديث يدعم:
  - HTML5
  - CSS3 (Gradients, Animations)
  - JavaScript (ES6)

لا توجد متطلبات خارجية أو مكتبات!

## 🛠️ التطوير والتخصيص

يمكنك تخصيص:
- ✏️ **الأسئلة**: عدّل `quizData` في `script.js`
- ✅ **الإجابات الصحيحة**: عدّل `correctAnswers` في `script.js`
- 🎨 **الألوان**: غيّر متغيرات CSS في `:root`
- 📝 **الرسائل**: عدّل نصوص النتائج في دالة `showResults()`
